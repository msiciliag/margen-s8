# Margen
Cuaderno personal de notas para escritorio y móvil. Permite escribir, buscar, archivar y restaurar notas. Las notas quedan guardadas en este dispositivo.

Usa Node 22.12 o posterior y npm. Instala las dependencias con npm ci. Ejecuta npm run dev y abre la dirección que aparece. Para comprobar el proyecto, usa npm test y npm run build. La compilación de los instaladores se hace en GitHub Actions siguiendo el cuaderno B.
